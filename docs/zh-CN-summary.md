## README 摘要

Harness engineering 装备一次运行;loop engineering 驱动多次运行;
**governance engineering**(治理工程)让这些循环保持诚实:状态权威、言行
对账、规则生命周期。

本仓库是 governance engineering 作为已建成系统的披露包——一套自主 LLM
agent 的执行治理层,于 2026 年 5-7 月间私下构建并实际使用。名称与许可证
(AGPL-3.0 代码 / CC BY-SA 4.0 文档)为已定 owner 裁决。包内包含设计思想
(essays/)、机制规格(specs/)与可核验的开发年表(CHRONOLOGY.md);实现代码有
意不公开(分级见 DISCLOSURE-MAP.md)。

问题层次:prompt engineering 塑造问什么,context engineering 塑造答题时
知道什么,harness engineering 塑造 agent 借以行动的机械,loop engineering
塑造长任务如何跨轮持续。这些之上还有一层尚未被塑造的问题:**自主运行凭什么
可信**——不是 agent 能不能干活,而是它对工作的陈述是否为真、计划接触现实
后发生了什么、以及管它的规则本身是否被管理。

本包记录的机制:两道阻塞式审计门(计划先审后执行、执行先审后收工,由运行
时钩子强制而非口头约定);言行对账(六项机器检查,对比状态"说了什么"与工
件"显示什么");四格偏差分类法(按计划/绕行/硬啃/上报——按偏差**许可的
响应**分类);证据分级状态(弱/中/强,收工需中级以上证据);自征税的规则
生命周期(每条规则必须付租,晋级需 owner 打勾,存疑机器进缓刑,死规则退休)。

许可:文档为 CC BY-SA 4.0(见 docs/LICENSE-DOCS.md);代码与技能文件
(首发时未收录,实现层按 DISCLOSURE-MAP.md 扣留)为 AGPL-3.0-or-later
(见 LICENSE)。

状态:名称(governance engineering)与许可证为已定 owner 裁决;实现层的任何
公开仍为逐项 owner 决定。首次发布已经发生(release v1.0,2026-07-08;
见 CHRONOLOGY.md);本仓库尚未记载发布之后的贡献政策。
